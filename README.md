# Random Password Generator (Генератор случайных паролей)

**Автор:** [Артур Латыпов]  
**Дата:** 28.04.2026  
**Язык:** Python 3.8+  
**Зависимости:** Только стандартная библиотека (tkinter, random, json)

Описание
Графическое приложение для генерации надёжных паролей с настраиваемыми параметрами. 
Поддерживает:
- Выбор длины пароля (ползунок)
- Включение/отключение цифр, букв и спецсимволов
- Валидацию входных данных
- Автоматическое сохранение и загрузку истории генераций в формате JSON
- Копирование результата в буфер обмена одним кликом

Установка и запуск
```bash
python main.py
